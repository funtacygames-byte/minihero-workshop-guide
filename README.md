# Make your first MiniHero mod

**English** · [简体中文](README.zh-CN.md)

Want to put your own treasure, character or adventure in the game? Start with a treasure that grants shield when you enter a stage. Find it in the game, change its value, then give it artwork, design an enemy or build an adventure of your own.

## Start here

1. [Make your first mod](docs/en/tutorials/first-mod.md): create a project, find Wayfarer's Relic in the codex and change its shield from 2 to 4.
2. [Build a playable stage](docs/en/tutorials/stage.md): place a guard and an exit, then play through it.
3. [Put your treasure in the stage](docs/en/tutorials/treasure.md): collect the relic and see its shield take effect in the next stage.

You need MiniHero, a code editor and a .NET SDK. [The first lesson walks through setup](docs/en/tutorials/first-mod.md#before-you-start). You can complete these three lessons without Unity, the game's source code or any artwork and music of your own.

## Get help

- **A build fails, content is missing or a change does not appear:** find the symptom in [Troubleshooting](docs/en/troubleshooting.md).
- **You are learning C# and would like help:** [Making mods with AI](docs/en/ai-authoring.md) includes prompts you can adapt.
- **You are writing code and need a field or event:** use the [API and rule references](docs/en/README.md#reference).
