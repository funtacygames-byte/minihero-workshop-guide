# 适用版本和已知限制

[English](../../en/reference/versions.md) · [目录](../README.md)

本教程修订 6，当前接口索引对应 **Mod API 1.10.0**。你可以直接用游戏生成的模组项目学习，不需要教程作者的工程或验证工具。

Windows x64 Mono 沙箱已通过本地开发构建检查，仍待发行构建验证和 Steam 上传。最新实现不设隔离宿主的固定内存、CPU 配额，也不设加载或调用的自动超时。保留的权限边界和兼容范围见 [C# 模组隔离](security.md)。

## 我的游戏能用这些例子吗？

教程的 C# 构建路线使用支持代码模组的 Windows Mono 游戏版本。项目目标为 `netstandard2.1`、C# 9，由游戏准备 API/Core 开发引用。你另需安装 .NET SDK；准备步骤见[首课](../tutorials/first-mod.md#开始前准备)。

如果编译报告缺少本课类型，先更新游戏、重新生成开发引用并构建。尤其是新卡牌选择需要 `CardChoiceRequest`、`CardChoiceEventContent` 和 `ICardChoiceResolver`。仅看到 API 版本字符串相同，不能保证早期安装已经包含后来增加的接口。不要把网页上的声明复制成一个假的 SDK。

加载器接受的 API 声明范围是 1.0.0～1.10.0。使用循环、种子或动态续接等 1.8 能力时，清单应声明 `modApiVersion: "1.8.0"`；旧模组能否继续使用，还取决于其实际调用的接口和存档内容。

## 做模组时要留意

| 情况 | 当前做法 |
| --- | --- |
| 改过的 C# 还是旧效果 | 递增包版本、重新构建安装，再完整退出重启；同进程重载不会卸载旧 DLL |
| 角色有多项初始招式 | 当前只有 `StartingMoveTypes` 的第一项成为初始招式 |
| 角色声明初始宝物 | `StartingTreasureTypes` 目前不在选角时发奖；用明确奖励奇遇 |
| 想让玩家调整模组设置 | 当前没有玩家 Mod 配置菜单；[配置 API](../tutorials/configuration.md)用于默认值和历史兼容 |
| 想换胜利页音乐 | `Victory` 尚未接入 Mod 胜利页；普通场景和 Boss 曲目另设 |
| 开始页被另一个模组替换 | 先只启用自己的替换页模组检查，再测试组合 |
| 切语言后旧卡面没变 | 已有牌可能保留文字；新开局或重新打开抉择检查 |
| 要发到 Steam | 在实际 Steam 环境上传，并检查条目和订阅下载；本地构建不代表已上线 |

自己的图片、音频、自定义页面和不同屏幕比例仍需在游戏中查看。改变冒险结构或内容 ID 后，先检查新局，再检查旧存档兼容性；不要直接拿唯一的旧存档尝试迁移。

## 修订 6 改了什么？

素材说明明确区分带背景的高竖幅角色主图与带背景的 4:5 头像，补上顶部裁切、真实编码、Alpha 和导出尺寸检查，并提供两张图分别制作的 AI 请求模板。角色与敌人课仍可先使用后备图片。

新增[职业与永久进度](../tutorials/profession-progress.md)（API 1.9.0）和[现有关卡难度扩展](../tutorials/level-difficulty.md)（API 1.10.0）。旧 1.x 模组保留原接口；新功能需要实际包含对应 API 的游戏引用。本教程上线不等于新版游戏已经在 Steam 发布。

本轮按当前代码及内置主图、头像文件核对背景和裁切规则，重建选定公开声明，编译两种语言的代码片段并检查链接与技术契约。中英文素材说明已逐项比较；这些检查不代替作者自己的图片实机验收、独立玩家试读或 Steam 上传。具体命令与结果记录在[维护记录](documentation-design.md)。

以前的接口核对、编译和运行记录保留在[维护记录](documentation-design.md)。它们说明当时检查过什么，不代表你的游戏版本、自己的素材、Steam 发布或所有存档组合都已验证。遇到问题按[排错指南](../troubleshooting.md)处理；文档版本变化见[更新记录](../../../CHANGELOG.md)。
