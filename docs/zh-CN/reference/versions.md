教程修订 4 · Mod API 1.8.0 · 2026-10-14

修订 4 是本地待提交 GitHub 的改动。玩法使用 C# 内容类，包清单、翻译表和存档是辅助数据；已从玩家及 AI 制作路线移除旧玩法 JSON 配方。当前有十五篇任务课、十五组中英源码片段和 65 个配对示例文本键。

## 适用基准

| 项目 | 依据 |
| --- | --- |
| API 与目标 | 当前 MiniHero.ModApi.Version 1.8.0；生成项目为 netstandard2.1 / C# 9 |
| 声明索引 | [87 个选定类型、773 条声明](api-surface.md)，含图节点／边与 protected 扩展点；不是整个 SDK |
| 开发引用 | 正式工程当前已编译 API/Core，只用于本地，没有放入教程仓库 |
| Unity | 已打开的正式 Editor 6000.3.19f1；临时验证脚本用后移出，未改玩法和场景制作参数 |
| 编译环境 | 当前本机 .NET SDK；此记录不定义最低支持 SDK |
| 能力状态 | [available/partial/backend-only](../../capabilities.json) 表示接入状态，不等于测试通过 |

加载器接受 API 声明 1.0.0～1.8.0。同版本字符串不证明旧 Core 已含最近新增选择接口；核对实际引用是否有 CardChoiceRequest、CardChoiceEventContent 和 ICardChoiceResolver。缺类型时更新游戏、重新生成引用，不能复制声明冒充 SDK。

本地验证器给每次测试编译使用独立程序集身份，因为 Editor 已加载过旧教程 DLL；这是测试隔离方法。作者应保留正常工程身份，并完整重启游戏完成发布验收；同进程重载不会卸载旧代码。
