## 仍须实际环境验收

- 独立游戏进程的完整退出／重启加载；同进程 DLL 加载不能替代它。
- 用户自备图像的实际裁切、音频播放及语言切换后的版面；工坊首页截图不证明这些素材已通过验收。
- Steam 提交、条目可见性和订阅下载；本地导出不证明这些步骤成功。
- 独立新手与英语读者的[试读](reader-trial.md)，尚未执行，AI 自审不算独立玩家验收。
- 旧游戏/API 和旧存档的迁移，以及完整高级 StageGraph／循环组合。
