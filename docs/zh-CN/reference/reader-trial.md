## 如何试读

请一位首次做模组的中文读者和一位使用英文教程的独立读者，各自从[首课](../tutorials/first-mod.md)开始；只提供教程、游戏和工具，不口头补齐遗漏步骤。取得参与者同意后记录操作与卡点，不收集账号凭据。

两位读者都应完成：创建 Sources → 修改并加载 2→4 → 固定关卡击败守卫与出口胜利 → 指定奖励宝物 → 下一场景检查护盾 → 用故意错误的入口或缺少注册内容练习排障。再按兴趣试角色、敌人或双语素材课。
