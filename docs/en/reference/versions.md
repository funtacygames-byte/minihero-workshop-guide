# Supported versions and known limitations

[简体中文](../../zh-CN/reference/versions.md) · [Index](../README.md)

Guide revision 5 covers **Mod API 1.8.0**. Follow it using the mod project generated by your game. You do not need the guide author's game project or verification tools.

The Windows x64 Mono sandbox has passed local development-build checks; release-build verification and Steam upload remain pending. The latest implementation has no fixed worker memory/CPU quotas or automatic loading/call deadlines. See [C# mod isolation](security.md) for the retained permission boundaries and compatibility details.

## Can my game use these examples?

The C# build route uses the Windows Mono game build with code-mod support. Generated projects target `netstandard2.1` and C# 9, and the game prepares the API/Core references. You also need a .NET SDK; see [the first lesson's setup](../tutorials/first-mod.md#before-you-start).

If a build reports missing lesson types, update the game, regenerate development references and rebuild. New card choices need `CardChoiceRequest`, `CardChoiceEventContent` and `ICardChoiceResolver`. A matching API version string alone does not guarantee that an early installation includes interfaces added later. Copying declarations from a webpage cannot replace the SDK.

The loader accepts API declarations from 1.0.0 to 1.8.0. For 1.8 features such as loops, seeds and dynamic continuation, declare `modApiVersion: "1.8.0"`. Compatibility of an older mod also depends on its actual API calls and saved content.

## Keep these limitations in mind

| Situation | Current behavior or workaround |
| --- | --- |
| Edited C# still shows an old effect | Increment the package version, rebuild/install and fully exit/restart; same-process reload does not unload the old DLL |
| A character lists several starting moves | Only the first `StartingMoveTypes` entry becomes the initial move |
| A character declares starting treasures | `StartingTreasureTypes` does not currently grant them at selection; use a reward encounter |
| You want players to adjust mod settings | There is no player-facing mod configuration menu; [configuration APIs](../tutorials/configuration.md) cover defaults and legacy values |
| You want custom victory-page music | `Victory` is not connected to mod victory pages; ordinary-stage and boss music have separate cues |
| Another mod replaces the start page | Test your replacement on its own before testing combinations |
| Old cards keep their text after a language change | Cards can retain text snapshots; check a new run or freshly opened choice |
| You want a Steam release | Upload in a real Steam environment and check the item and subscribed download; a local build is not an online release |

Check your own images, audio, custom pages and screen ratios in the game. After changing an adventure's structure or content IDs, check a fresh run before testing old-save compatibility. Keep a recoverable copy rather than experimenting on your only save.
