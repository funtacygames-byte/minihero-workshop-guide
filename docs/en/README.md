## Learning path

Complete the first lesson, then choose your task. Each lesson lists prerequisites, edited files, and observable results. Actual-effect checks do not depend on random draws.

| Lesson | Outcome |
| --- | --- |
| [Build and change your first mod](tutorials/first-mod.md) | Verify loading in the codex and change 2→4 |
| [Treasures](tutorials/treasure.md) | Quality, levels, pools, and a specific reward |
| [Characters and initial moves](tutorials/character.md) | Registration, selection, and two-target checks |
| [Enemies and traits](tutorials/enemy.md) | Card instances, damage windows, independent state |
| [Your first fixed stage](tutorials/stage.md) | Guard→exit, fixed columns, and playability |
| [Connect stages](tutorials/adventure.md) | Steps, intermissions, stage IDs, save restoration |
| [Assets, music, and bilingual text](tutorials/assets-and-text.md) | Slots, package paths, and shared arguments |
| [Package, publish, and update](tutorials/publish.md) | Verify local builds and Steam delivery separately |
